# ونيس (Wanees) 🦊
> موقع وتطبيق دردشة عربي ذكي وودود، مبني بتقنية Flutter وقابل للتشغيل كـ Flutter Web والتحويل مستقبلاً إلى تطبيقات أندرويد (Android) وآيفون (iOS).

---

## 🌟 نبذة عن المشروع
**ونيس** هو رفيق محادثة عربي ذكي، مستوحى من فكرة تطبيقات المؤانسة الذكية (مثل SimSimi) ولكن بهوية وشخصية عربية أصيلة ودافئة. يتميز ونيس بـ:
- **دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL)**.
- **ردود محلية ذكية وفورية** لأشهر التحيات والأسئلة الشائعة بدون استهلاك API.
- **ذكاء اصطناعي عبر Gemini API** لأي سؤال أو استفسار عام.
- **حماية تامة للمفاتيح السرية**: قراءة المفتاح عبر `--dart-define=GEMINI_API_KEY` دون وضعه في الكود.
- **واجهات متجاوبة كاملة**:
  1. 🏠 **الرئيسية (Home)**: ترحيب، أزرار البدء، استعراض الميزات.
  2. 💬 **المحادثة (Chat)**: شات تفاعلي، رسائل المستخدم يمين، رسائل ونيس يسار، مؤشر كتابة ذكي، اقتراحات سريعة، ومسح المحادثة.
  3. 🔑 **تسجيل الدخول (Login)**: واجهة دخول وإنشاء حساب ومتابعة كضيف.
  4. 👤 **الملف الشخصي (Profile)**: بيانات المستخدم، حالة الاشتراك، إحصائيات، وتعديل الحساب.
  5. ⚙️ **الإعدادات (Settings)**: التحكم بالألوان، الإشعارات والأصوات، ومسح السجلات.
  6. 💎 **الاشتراك (Subscription)**: مقارنة الخطة المجانية مع "ونيس بلس" والتبديل بين الشهري والسنوي.

lib/

│   ├── chat_screen.dart           # شاشة الدردشة والتفاعل
│   ├── login_screen.dart          # شاشة تسجيل الدخول

## 🚀 طريقة التشغيل (Flutter Web / Codespaces)

### 1. تثبيت الحزم:
```bash
flutter pub get
```

### 2. التشغيل على خادم الويب (مع تمرير مفتاح Gemini):
```bash
flutter run -d web-server --web-hostname 0.0.0.0 --web-port 8080 --dart-define=GEMINI_API_KEY=YOUR_KEY
```

> **ملاحظة:** استبدل `YOUR_KEY` بمفتاح Gemini الخاص بك. وفي حال عدم تمريره، سيعمل التطبيق تلقائياً بالردود المحلية الترحيبية الذكية.

### 3. إذا كان المنفذ 8080 مشغولاً:
```bash
flutter run -d web-server --web-hostname 0.0.0.0 --web-port 8082 --dart-define=GEMINI_API_KEY=YOUR_KEY
```
